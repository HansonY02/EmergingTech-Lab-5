# Revision evidence
The constructed v0 negative-control response passes basic JSON validation but makes two substantive errors: it lets posture rewrite general stage and uses broad sector AI data as application diffusion. This is a deliberately constructed failing candidate, not an independently observed historical model run. The weakness in the preliminary specialist instructions was real: they invited stage adaptation and offered no denominator rule.
Revision: version 1.0 requires a defined adopter unit, application-specific denominators, explicit abstention, fixed general evidence across contrasts, and assisted/autonomous separation. It also prohibits full adoption decisions. Final outputs reject the negative-control claims.
